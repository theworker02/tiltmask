# tiltmask

Tilt color mask values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/tiltmask/

## Install / run

```bash
git clone https://github.com/theworker02/tiltmask.git
cd tiltmask
node src/cli.js
node --test
```
